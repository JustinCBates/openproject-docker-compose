# Integration Test for Proxy Configuration

## Purpose
This integration test validates the user-provided proxy and server settings from `.cfg` by deploying a minimal Docker container that serves a Hello World page via HTTP/HTTPS. It allows users to probe the endpoints, receive feedback, and adjust configuration before proceeding to a full OpenProject build.

## Control Flow

1. **Read Configuration**
   - Load settings from `.cfg` generated by the interactive configuration script.

2. **Render and Launch Container**
   - Render a minimal Caddyfile and Hello backend using current config.
   - Build and start the Docker container(s).

3. **Probe/Test Endpoints**
   - Display HTTP/HTTPS endpoints for user testing.
   - Allow user to verify connectivity and correct proxy behavior.

4. **Feedback and Suggestions**
   - Prompt user for feedback on test results.
   - Suggest configuration changes if issues are detected.

5. **Teardown**
   - Stop and remove containers and temporary files after user confirmation.
   - Ensure no residue is left behind.

6. **Prepare for Full Build**
   - If integration test passes, proceed to full OpenProject stack build.
