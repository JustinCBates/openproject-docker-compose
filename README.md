# OpenProject Orchestrator - Build Branch

This branch contains build automation and release artifacts.

## Installation

Install the latest release:
```bash
pip install openproject-orchestrator
```

Or download from [Releases](https://github.com/JustinCBates/openproject-docker-compose/releases).
