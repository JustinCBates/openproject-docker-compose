# Project Documentation

This directory contains project overview and summary documentation for the OpenProject Docker Compose system.

## Documents

### **PROJECT_OVERVIEW.md**
- **Purpose**: Complete project overview and component descriptions
- **Audience**: Anyone new to the project, stakeholders, system administrators
- **Content**: System purpose, component descriptions, usage instructions
- **Scope**: High-level understanding of the entire system

### **PROJECT_STRUCTURE_MASTER.md**
- **Purpose**: Master reference for project structure
- **Audience**: Developers, architects
- **Content**: Complete directory structure and organization
- **Scope**: System architecture and file organization

### **MULTI_REPO_SUMMARY.md**
- **Purpose**: Multi-repository structure and relationships
- **Audience**: Developers, contributors, project maintainers
- **Content**: Repository organization, component relationships, development workflow
- **Scope**: Multi-repo architecture and coordination

### **BRANCH_RESTRUCTURE_COMPLETE.md**
- **Purpose**: Documentation of branch restructuring completion
- **Audience**: Project maintainers, DevOps
- **Content**: Branch structure changes, backup tags, safety measures
- **Scope**: Git repository organization and branch management

### **DEPENDENCY_ANALYSIS.md**
- **Purpose**: Cross-repository dependency analysis
- **Audience**: Developers, system administrators
- **Content**: Production vs development dependencies, version conflicts, shared packages
- **Scope**: Python package dependencies across all 7 repositories

## Usage

These documents provide the essential context for understanding what this project does and how it's organized.

- **Start with PROJECT_OVERVIEW.md** if you're new to the project
- **Reference PROJECT_STRUCTURE_MASTER.md** for detailed directory structure
- **Check MULTI_REPO_SUMMARY.md** to understand the repository structure
- **Review BRANCH_RESTRUCTURE_COMPLETE.md** for current branch organization
- **See DEPENDENCY_ANALYSIS.md** for package dependency information
