# Package File Management Strategy - Addendum to TUI Proposal

**Created**: October 16, 2025  
**Purpose**: Address file location management for packaged submodules  
**Related**: MAIN_PROJECT_TUI_PROPOSAL.md

---

## Problem Statement

When submodules are packaged and installed via pip, they:
- ❌ Don't have predictable directory structures
- ❌ Can't write to their installation directories (read-only)
- ❌ Can't assume relative paths for templates, defaults, or outputs
- ❌ Need to be told where to find inputs and write outputs

**Key Insight**: Packaged Python code lives in `site-packages/` which is:
- Read-only for the application
- Not a good place for user data
- Variable location across installations

---

## Solution: Workspace-Based Architecture

### Core Principle

**The main orchestrator owns the workspace** and provides paths to submodules:

```
/opt/openproject/                    ← Workspace root (user-controlled)
├── config/                          ← Config files (writable)
│   ├── .env                         ← Generated by config-manager
│   ├── interactive_config.cfg       ← Generated by config-manager
│   └── defaults.yml                 ← From orchestrator's package data
│
├── templates/                       ← Templates (from orchestrator package)
│   ├── Caddyfile.j2
│   ├── nginx.conf.j2
│   └── docker-compose.override.yml.j2
│
├── outputs/                         ← Deploy outputs (writable)
│   ├── Caddyfile                    ← Rendered by deploy-manager
│   ├── nginx.conf
│   └── docker-compose.override.yml
│
├── backups/                         ← Backups (writable)
│   └── openproject_backup_20251016/
│
├── data/                            ← Persistent data (writable)
│   ├── postgres/
│   ├── openproject/
│   └── logs/
│
└── .openproject/                    ← Metadata (hidden, writable)
    ├── state.json                   ← Orchestrator state
    ├── deployment_history.json      ← Deployment tracking
    └── cache/                       ← Cached data
```

**Submodules never assume paths** - they receive all paths as parameters.

## Implementation Strategy

### 1. Workspace Manager

**Location**: `src/openproject_orchestrator/workspace/workspace_manager.py`

**Purpose**: Centralized workspace and path management

```python
from pathlib import Path
from typing import Dict, Optional
import json
from dataclasses import dataclass, asdict
from datetime import datetime

@dataclass
class WorkspaceConfig:
    """Workspace configuration"""
    workspace_root: Path
    config_dir: Path
    templates_dir: Path
    outputs_dir: Path
    backups_dir: Path
    data_dir: Path
    metadata_dir: Path
    created_at: datetime
    last_modified: datetime
    version: str = "2.0.0"
    

class WorkspaceManager:
    """
    Manages workspace directory structure and provides paths to submodules.
    
    The workspace is the main orchestrator's responsibility. Submodules
    receive paths as parameters and never assume file locations.
    """
    
    DEFAULT_STRUCTURE = {
        'config': 'Configuration files (.env, .cfg, defaults)',
        'templates': 'Jinja2 templates for deployment',
        'outputs': 'Rendered templates and generated files',
        'backups': 'Backup storage',
        'data': 'Persistent application data',
        '.openproject': 'Metadata and state (hidden)',
    }
    
    def __init__(self, workspace_root: Optional[Path] = None):
        """
        Initialize workspace manager
        
        Args:
            workspace_root: Root directory for workspace
                           Defaults to current directory
        """
        self.workspace_root = Path(workspace_root or Path.cwd()).resolve()
        self.config_file = self.workspace_root / '.openproject' / 'workspace.json'
        
        # Load or create workspace config
        if self.config_file.exists():
            self.config = self._load_config()
        else:
            self.config = self._create_workspace()
    
    def _create_workspace(self) -> WorkspaceConfig:
        """Create new workspace structure"""
        console.print(f"\n[cyan]Creating workspace at: {self.workspace_root}[/cyan]\n")
        
        # Create directory structure
        dirs = {
            'config_dir': self.workspace_root / 'config',
            'templates_dir': self.workspace_root / 'templates',
            'outputs_dir': self.workspace_root / 'outputs',
            'backups_dir': self.workspace_root / 'backups',
            'data_dir': self.workspace_root / 'data',
            'metadata_dir': self.workspace_root / '.openproject',
        }
        
        for name, path in dirs.items():
            path.mkdir(parents=True, exist_ok=True)
            console.print(f"  ✓ Created: {path.relative_to(self.workspace_root)}")
        
        # Copy default templates from package data
        self._install_default_templates()
        
        # Copy default configs from package data
        self._install_default_configs()
        
        # Create workspace config
        config = WorkspaceConfig(
            workspace_root=self.workspace_root,
            created_at=datetime.now(),
            last_modified=datetime.now(),
            **dirs
        )
        
        # Save config
        self._save_config(config)
        
        console.print(f"\n[green]✓ Workspace initialized[/green]\n")
        return config
    
    def _install_default_templates(self):
        """
        Copy default templates from package data to workspace
        
        Templates are embedded in the orchestrator package using
        importlib.resources (Python 3.9+) or pkg_resources
        """
        from importlib import resources
        import shutil
        
        # Package data location
        try:
            # Python 3.9+
            template_files = resources.files('openproject_orchestrator.data.templates')
        except AttributeError:
            # Python 3.8 fallback
            import pkg_resources
            template_path = pkg_resources.resource_filename(
                'openproject_orchestrator', 
                'data/templates'
            )
            template_files = Path(template_path)
        
        # Copy templates to workspace
        templates = [
            'Caddyfile.j2',
            'nginx.conf.j2',
            'docker-compose.override.yml.j2',
            'docker-compose.pgadmin.yml.j2',
        ]
        
        for template_name in templates:
            try:
                if hasattr(template_files, 'joinpath'):
                    # Python 3.9+
                    template_content = (template_files / template_name).read_text()
                    dest = self.config.templates_dir / template_name
                    dest.write_text(template_content)
                else:
                    # Python 3.8
                    src = template_files / template_name
                    dest = self.config.templates_dir / template_name
                    shutil.copy2(src, dest)
                
                console.print(f"  ✓ Installed template: {template_name}")
            except Exception as e:
                console.print(f"  [yellow]⚠ Could not install {template_name}: {e}[/yellow]")
    
    def _install_default_configs(self):
        """
        Copy default configuration files from package data
        
        This includes:
        - defaults.yml (system defaults)
        - openproject_template.yml (OpenProject-specific defaults)
        """
        from importlib import resources
        
        try:
            config_files = resources.files('openproject_orchestrator.data.configs')
        except AttributeError:
            import pkg_resources
            config_path = pkg_resources.resource_filename(
                'openproject_orchestrator',
                'data/configs'
            )
            config_files = Path(config_path)
        
        defaults = [
            'defaults.yml',
            'openproject_template.yml',
        ]
        
        for config_name in defaults:
            try:
                if hasattr(config_files, 'joinpath'):
                    content = (config_files / config_name).read_text()
                    dest = self.config.config_dir / config_name
                    dest.write_text(content)
                else:
                    src = config_files / config_name
                    dest = self.config.config_dir / config_name
                    shutil.copy2(src, dest)
                
                console.print(f"  ✓ Installed config: {config_name}")
            except Exception as e:
                console.print(f"  [yellow]⚠ Could not install {config_name}: {e}[/yellow]")
    
    def _save_config(self, config: WorkspaceConfig):
        """Save workspace configuration"""
        self.config_file.parent.mkdir(parents=True, exist_ok=True)
        
        # Convert paths to strings for JSON serialization
        config_dict = asdict(config)
        for key, value in config_dict.items():
            if isinstance(value, Path):
                config_dict[key] = str(value)
            elif isinstance(value, datetime):
                config_dict[key] = value.isoformat()
        
        with open(self.config_file, 'w') as f:
            json.dump(config_dict, f, indent=2)
    
    def _load_config(self) -> WorkspaceConfig:
        """Load workspace configuration"""
        with open(self.config_file, 'r') as f:
            data = json.load(f)
        
        # Convert strings back to paths
        for key in ['workspace_root', 'config_dir', 'templates_dir', 
                    'outputs_dir', 'backups_dir', 'data_dir', 'metadata_dir']:
            data[key] = Path(data[key])
        
        # Convert ISO strings back to datetime
        for key in ['created_at', 'last_modified']:
            data[key] = datetime.fromisoformat(data[key])
        
        return WorkspaceConfig(**data)
    
    def get_paths(self) -> Dict[str, Path]:
        """
        Get all workspace paths for passing to submodules
        
        Returns:
            Dictionary of path names to Path objects
        """
        return {
            'workspace_root': self.config.workspace_root,
            'config_dir': self.config.config_dir,
            'templates_dir': self.config.templates_dir,
            'outputs_dir': self.config.outputs_dir,
            'backups_dir': self.config.backups_dir,
            'data_dir': self.config.data_dir,
            'metadata_dir': self.config.metadata_dir,
        }
    
    def get_config_manager_paths(self) -> Dict[str, Path]:
        """
        Get paths specific to config-manager
        
        Config-manager needs:
        - output_dir: Where to write .env, .cfg files
        - defaults_file: Default values to use
        - cache_dir: For caching discovery results
        """
        return {
            'output_dir': self.config.config_dir,
            'defaults_file': self.config.config_dir / 'defaults.yml',
            'cache_dir': self.config.metadata_dir / 'cache',
        }
    
    def get_deploy_manager_paths(self) -> Dict[str, Path]:
        """
        Get paths specific to deploy-manager
        
        Deploy-manager needs:
        - config_file: Input configuration (.env or .cfg)
        - templates_dir: Where to find Jinja2 templates
        - output_dir: Where to write rendered files
        - compose_file: docker-compose.yml location
        - snapshot_dir: Where to store snapshots
        """
        return {
            'config_file': self.config.config_dir / 'interactive_config.cfg',
            'env_file': self.config.config_dir / '.env',
            'templates_dir': self.config.templates_dir,
            'output_dir': self.config.outputs_dir,
            'compose_file': self.workspace_root / 'docker-compose.yml',
            'snapshot_dir': self.config.backups_dir / 'snapshots',
        }
    
    def get_maintenance_paths(self) -> Dict[str, Path]:
        """
        Get paths specific to maintenance operations
        
        Maintenance needs:
        - backups_dir: Where to store backups
        - data_dir: Where application data lives
        - config_dir: Configuration to backup
        """
        return {
            'backups_dir': self.config.backups_dir,
            'data_dir': self.config.data_dir,
            'config_dir': self.config.config_dir,
        }
    
    def validate_workspace(self) -> bool:
        """
        Validate workspace structure
        
        Returns:
            True if workspace is valid
        """
        required_dirs = [
            self.config.config_dir,
            self.config.templates_dir,
            self.config.outputs_dir,
            self.config.backups_dir,
            self.config.data_dir,
            self.config.metadata_dir,
        ]
        
        all_exist = all(d.exists() and d.is_dir() for d in required_dirs)
        
        if not all_exist:
            console.print("[yellow]⚠ Workspace structure incomplete[/yellow]")
            for d in required_dirs:
                status = "✓" if d.exists() else "✗"
                console.print(f"  {status} {d.relative_to(self.workspace_root)}")
        
        return all_exist
    
    def show_workspace_info(self):
        """Display workspace information"""
        from rich.tree import Tree
        
        tree = Tree(f"[bold cyan]Workspace: {self.workspace_root}[/bold cyan]")
        
        tree.add(f"[green]config/[/green] - Configuration files")
        tree.add(f"[green]templates/[/green] - Jinja2 templates")
        tree.add(f"[green]outputs/[/green] - Rendered files")
        tree.add(f"[green]backups/[/green] - Backup storage")
        tree.add(f"[green]data/[/green] - Application data")
        tree.add(f"[dim].openproject/[/dim] - Metadata (hidden)")
        
        console.print(tree)
        console.print(f"\n[dim]Created: {self.config.created_at.strftime('%Y-%m-%d %H:%M:%S')}[/dim]")
        console.print(f"[dim]Version: {self.config.version}[/dim]")
```

class ConfigCoordinator:
    """Coordinates config-manager submodule"""
    
    def __init__(self, workspace: WorkspaceManager):
        self.console = Console()
        self.workspace = workspace
        self.config_mgr = None
        self.state = ConfigState()
        
    def run_interactive_configuration(
        self,
        template: str = "openproject",
        prober_enabled: bool = True,
    ) -> ConfigResult:
        """
        Run interactive configuration using config-manager
        
        KEY CHANGE: Pass workspace paths to config-manager
        """
        self.console.print("\n[cyan]Starting Interactive Configuration...[/cyan]\n")
        
        # Get paths from workspace manager
        paths = self.workspace.get_config_manager_paths()
        
        # Initialize config-manager WITH PATHS
        self.config_mgr = ConfigurationManager(
            template=template,
            output_dir=paths['output_dir'],          # ← Where to write files
            defaults_file=paths['defaults_file'],    # ← Default values
            cache_dir=paths['cache_dir'],            # ← Cache location
        )
        
        # Run the 5-phase workflow
        result = self.config_mgr.run_interactive(
            prober_enabled=prober_enabled,
            resume=False
        )
        
        if result.success:
            self.state.is_configured = True
            self.state.config_file = paths['output_dir'] / 'interactive_config.cfg'
            self.state.env_file = paths['output_dir'] / '.env'
            self.state.configuration = result.configuration
            
            self.console.print(f"\n[green]✓[/green] Configuration saved:")
            self.console.print(f"  • Config: {self.state.config_file}")
            self.console.print(f"  • Env:    {self.state.env_file}")
        
        return result

# In deploy-manager: src/openproject_deploy_manager/__init__.py

class DeploymentOrchestrator:
    """
    UPDATED: Accept paths as parameters
    """
    
    def __init__(
        self,
        config: Dict[str, Any],
        config_file: Optional[Path] = None,      # ← NEW: Input config file
        templates_dir: Optional[Path] = None,    # ← NEW: Templates location
        output_dir: Optional[Path] = None,       # ← NEW: Where to write rendered files
        compose_file: Optional[Path] = None,     # ← NEW: docker-compose.yml
        snapshot_dir: Optional[Path] = None,     # ← NEW: Snapshot storage
    ):
        """
        Initialize deployment orchestrator
        
        Args:
            config: Configuration dictionary
            config_file: Path to config file (for loading if config not provided)
            templates_dir: Directory containing Jinja2 templates
                          Defaults to ./templates
            output_dir: Directory for rendered outputs
                       Defaults to ./outputs
            compose_file: Path to docker-compose.yml
                         Defaults to ./docker-compose.yml
            snapshot_dir: Directory for deployment snapshots
                         Defaults to ./backups/snapshots
        """
        self.config = config
        self.config_file = config_file
        self.templates_dir = Path(templates_dir or Path.cwd() / 'templates')
        self.output_dir = Path(output_dir or Path.cwd() / 'outputs')
        self.compose_file = Path(compose_file or Path.cwd() / 'docker-compose.yml')
        self.snapshot_dir = Path(snapshot_dir or Path.cwd() / 'backups' / 'snapshots')
        
        # Ensure directories exist
        self.output_dir.mkdir(parents=True, exist_ok=True)
        self.snapshot_dir.mkdir(parents=True, exist_ok=True)
        
        # Verify templates directory exists
        if not self.templates_dir.exists():
            raise ValueError(f"Templates directory not found: {self.templates_dir}")
    
    def render_templates(self) -> TemplateResult:
        """
        Render Jinja2 templates
        
        Templates are loaded from self.templates_dir
        Outputs are written to self.output_dir
        """
        from jinja2 import Environment, FileSystemLoader
        
        # Create Jinja2 environment pointing to templates dir
        env = Environment(loader=FileSystemLoader(self.templates_dir))
        
        # Render each template
        templates = [
            'Caddyfile.j2',
            'nginx.conf.j2',
            'docker-compose.override.yml.j2',
        ]
        
        for template_name in templates:
            template = env.get_template(template_name)
            rendered = template.render(**self.config)
            
            # Write to output dir
            output_file = self.output_dir / template_name.replace('.j2', '')
            output_file.write_text(rendered)
        
        return TemplateResult(success=True)

### 7. CLI with Workspace Support

**Updated CLI**: `src/openproject_orchestrator/cli.py`

```python
import click
from pathlib import Path
from rich.console import Console
from openproject_orchestrator.tui_controller import TUIController
from openproject_orchestrator.workspace.workspace_manager import WorkspaceManager

console = Console()

@click.group()
@click.version_option(version="2.0.0")
@click.option(
    '--workspace', '-w',
    type=click.Path(),
    default=None,
    help='Workspace directory (defaults to current directory)'
)
@click.pass_context
def main(ctx, workspace):
    """OpenProject Deployment Orchestrator"""
    ctx.ensure_object(dict)
    
    # Initialize workspace
    workspace_root = Path(workspace) if workspace else Path.cwd()
    ctx.obj['workspace'] = WorkspaceManager(workspace_root)

@main.command()
@click.pass_context
def deploy(ctx):
    """
    Launch interactive TUI for deployment
    """
    workspace = ctx.obj['workspace']
    controller = TUIController(workspace=workspace)
    controller.run()

@main.command()
@click.pass_context
def init(ctx):
    """
    Initialize workspace in current directory
    """
    workspace = ctx.obj['workspace']
    
    if workspace.config_file.exists():
        console.print("[yellow]Workspace already initialized[/yellow]")
        workspace.show_workspace_info()
    else:
        # Workspace is created automatically by WorkspaceManager
        console.print("[green]✓ Workspace initialized[/green]")
        workspace.show_workspace_info()

@main.command()
@click.pass_context
def info(ctx):
    """
    Show workspace information
    """
    workspace = ctx.obj['workspace']
    workspace.show_workspace_info()

@main.command()
@click.option('--template', default='openproject', help='Configuration template')
@click.option('--prober/--no-prober', default=True, help='Enable prober validation')
@click.pass_context
def configure(ctx, template, prober):
    """Run configuration only"""
    workspace = ctx.obj['workspace']
    controller = TUIController(workspace=workspace)
    controller.config_coordinator.run_interactive_configuration(
        template=template,
        prober_enabled=prober
    )
```

- No assumptions about directory structure

### Deploy-Manager (Submodule Package)

✅ **Update API**:
- Accept `config_file` parameter (input config)

- Accept `output_dir` parameter (where to write rendered files)
- Accept `compose_file` parameter (docker-compose.yml location)
- Accept `snapshot_dir` parameter (snapshot storage)
- No assumptions about directory structure
